Feature 13: Technical Architecture & MVC Separation

This module serves as the central communication backbone for HireIQ. It is built strictly under the Model-View-Controller (MVC) paradigm without placing any mail business logic in the presentation layer:

1. Models (`models/`)

  • EmailTemplate.js: Encapsulates template definitions, schema validation, and dynamic variable interpolation with regex token matching.
  • EmailLog.js: Manages transactional persistence of message delivery records, error logging, and performance metrics.

2. Controllers (`controllers/`)

  • emailController.js: Coordinates HTTP requests, validates subject/body updates, generates live HTML previews, handles manual retry invocations, and returns structured API responses.

3. Views (`public/`)

  • email-manager.html: Responsive administrative dashboard. Allows live editing with placeholder pills, viewing rendered HTML previews, and tracking delivery audit logs.

Queue Processing & Resilience Logic

In accordance with Software Engineering best practices, email dispatching is decoupled from user-facing transactions via services/emailService.js:

  1. Asynchronous Non-Blocking Enqueue: Requests return immediately to the caller while the email is saved as Queued.
  2. Automatic Retry with Exponential Backoff: If a transient transport error occurs, the engine re-queues the email up to max_attempts = 3 before marking it permanently Failed.
  3. 1-Click Manual Remediation: Recruiters or admins can click "Retry" in the UI, which re-queues the message and executes a fresh dispatch.
